# 图像／视频清晰化

快速生成页提供独立的“图像／视频清晰化”入口；图片、视频生成结果和装配成片也可直接送入此入口。没有作品时沿用快速草稿创建机制。

第一版使用 RealESRGAN_x2plus.pth，宽高各放大两倍，保持画幅。图片保存为 PNG；视频逐帧处理后沿用原帧率和单条原音轨。AI 可能改变纹理，逐帧增强不能保证消除模糊、重建真实细节或解决闪烁，需要比较原素材和结果。

可选择当前作品登记的素材、历史成功任务候选或上传新素材。不要求先采用样片，不改写分镜、装配或审核记录。结果登记为独立任务候选；所有处理记录可分页查看，原素材和结果分别提供预览与下载。现有已采用样片的 `finish-tasks` 接口保持兼容。

## 当前边界

- 静态 PNG、JPEG、WebP，最多 840 万输入像素；不支持动画图片，图片处理链不保留透明通道。
- MP4、MOV、WebM、MKV，1–60 fps，最多一条音轨；不做补帧或声音增强。
- 视频单帧最多 420 万输入像素，同时限制 30 秒、600 帧、累计 2.56 亿输入像素。例如 1344×768 的 24 fps 视频约可处理 10 秒。
- 单文件最多 2 GB。当前 ComfyUI 节点按整段加载，长度限制用于控制内存；长片请先按片段处理。流式长片增强和更多超分模型尚未实现。
- 服务器先解码检查输入，再冻结素材、图和模型参数，通过已有 GPU 调度器执行。视频结果核对尺寸、帧数、帧率、音轨数和时长，图片核对 2× 尺寸；不符合时保留输出和回执供核对。

## API

所有入口沿用作品归属鉴权，写入沿用现有会话与 Origin 校验，不接受客户端指定模型、输出目录或工作流。

- `GET /api/projects/{project_id}/enhancement-capability`：节点及模型可用性、倍数和资源边界。
- `GET /api/projects/{project_id}/enhancements?offset=0`：当前作品允许的原素材、最多 20 条清晰化任务和 `next_offset`。
- `POST /api/projects/{project_id}/enhancement-tasks`：`{"source":"已登记素材引用","idempotency_key":"客户端唯一请求标识"}`，返回 202 和已有任务格式。
- 沿用作品任务详情、停止、核对和 `submission-receipt` 接口。相同标识与参数找回原任务；参数不同返回 409，不重复排队。浏览器在网络结果不明时保留原请求，刷新后查询回执。

无需数据库迁移、新依赖或修改既有请求格式。真实模型执行与浏览器隔离合成测试的证据须分别记录，技术成功不等于艺术审核通过。
