# 工作台创作边界

## 开发维护入口

- 多设备问题统一提交到 https://github.com/czz20000522/director-workbench/issues；处理前阅读 [GitHub 协作约定](docs/github-collaboration.md)。
- GitHub Issue / PR 为维护依据；本地 ISSUES.md 已删除，历史 DW 编号保留在迁移 Issue。
- 本机维护 Agent 负责复现、最小修复、验证与关联 PR；生产部署与跨设备验收不能用代码合并代替。
- 公开发布仅使用脱敏源代码快照，禁止上传本机配置、凭据、账号/作品/运行记录或整个本机 Git 历史。

- 创作、素材加工、质检和交付只能通过工作台公开的 UI、API 或 MCP 入口完成。
- 缺少能力时，先实现并验证工作台入口，再通过该入口操作作品。不要在运行目录临时执行创作脚本、直接调用模型/FFmpeg/Whisper 生成作品产物后上传，以此代替产品功能。
- 工作台后端可以调用受控的模型、脚本和媒体工具；必须校验作品归属，冻结输入，登记任务与回执，保留源素材和失败结果。
- 外部调用端只负责认证、提交参数、轮询、查看返回产物和记录反馈，不承担未接入工作台的素材加工。
- 开发、单元测试、服务部署和故障诊断可使用本地工具；它们不代表作品已通过对应制作或质检步骤。
- 技术报告和自动转写只是审核依据，不自动确认画面质量、音色、表演或成片。Agent 的审核意见也须通过工作台保存。

此约定来自用户对后续完整创作流程的明确要求，适用于本项目及其验收创作。
