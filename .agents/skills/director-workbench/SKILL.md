# 使用导演工作台

以用户提供的 URL 为唯一入口，不猜服务器路径、端口、账号或技术配方。GET `/.well-known/director-workbench.json`，读其 `start`，再按需读取能力分组和认证后的 OpenAPI。Skill 不包含部署地址或凭据；使用当前服务返回的合同，不沿用旧配方要求。

## 身份与目标

按入门说明以本人账号登录，凭据只保留在可信客户端的会话容器。HTTP Cookie/Bearer 与远程 MCP 共用真实账号权限。先核对当前身份，再列本人作品；无法确定会影响哪一个已有作品时询问。401 停止后续写入并重新登录，404 不猜他人作品，409 重读并比较，不提升版本盲目覆盖。远程 MCP 首批要求客户端能配置 Bearer；仅支持 OAuth 的宿主目前不支持。无需给 Agent SSH 管理员权限。

## 最短创作流程

1. 读取目标作品的计划和状态；没有目标且用户要求新小样时，通过公开创建接口建立作品，保留返回的 ID。创建不是幂等操作，响应未知先列作品核对。
2. 原样保留用户描述。用户没有参数时可采用5秒横屏、auto；用户明确的合法时长、画幅和种子优先。H3 单段4–15秒，实际帧数与输出时长以预检为准。复杂长篇或多段扩张超出当前授权时先明确范围。
3. 保存高层分镜，使用真实计划 revision。不要求安装工作流或猜 stage_id。没有开始图可纯文本；上传素材使用公开上传回执，图片在素材库存在不代表已绑定为开始图。角色参考、结束画面、表演声音、完整母版各有用途，不互相冒充。未支持组合保留输入并说明缺口，不偷偷忽略。
4. 用 `auto` 无生成预检，读取准备度、blockers、allowed_actions、next_actions 和实际规格。预检不代表提交或生成；读计划、预检不应写入或改变 revision。
5. 用户明确“生成看看/按这段跑”即授权一次小样的必要准备与原任务提交，无需每个机械步骤再询问。仅解释、草稿或预检指令不授权生成。先保留唯一 idempotency_key 与参数，通过原 tasks 提交一次。未知响应先按原键查 submission-receipt；不换键重发计费操作。
6. 读取原队列与任务回执。等待、停止请求、待核对、成功是不同状态；待核对先核对原执行，不自动重复生成。成功后打开真实媒体候选和历史，不能仅凭任务成功声称看过、听过、审核通过、已采用或已交付。

## 页面可见与接管

需要可见操作时，让用户在目标标签页允许 Agent 引导。通过页面能力分组发现本人页面，用明确 page_id、目标作品/分镜/版本和唯一 action_id 请求显示未保存草稿、定位、导航、候选、播放或暂停。只允许结构化表现动作，不运行任意 DOM 脚本。

页面动作不再保存或生成；业务调用仍只有一次。草稿显示后等待真实页面回执，再通过原保存接口写入；随后定位原准备度与任务。`pending` 只表示待呈现；无附属页、组件不可见、目标变化或播放限制应返回未呈现。没有页面的 HTTP/MCP Agent 仍可完成业务，但不能声称已点击或播放。手动接管、未保存输入、刷新和版本变化应停止冲突动作；不要为了展示进度反复抢回用户正在浏览的页面。

读取原页面组件的确认，不自行登记伪页面或发送ACK。确认是`client_report/not_attested`，不证明用户已看过或听过。首轮播放适配只打开当前候选；指定旧task不匹配时返回未呈现，不为播放暗中恢复历史版本。人工导航或编辑会自动接管；重新引导须用户明确允许，接管不会撤销已提交任务。

## 修改、审核与交接

使用实际服务发现的工具或 HTTP 原业务路线修改分镜、上传、取消、查看版本、审核接点、设置全片声音、装配。详细参数按需读对应 schema，勿一次倾倒全部工具到上下文。写入需核对版本及返回结果；非幂等写入响应未知先核对保存内容。技术诊断和 ASR 是证据，不替代主观听看；审核、采用、删除、交付按用户明确意图及原业务门禁执行。

MCP 返回 `ok=false` 是业务失败，即使传输成功。交接保留作品 ID、计划 revision、请求键、任务/候选 ID、真实回执、已验证内容与剩余限制。将草稿、预检、生成、审核和采用分别表述，不伪造完成。
